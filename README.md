# Битка за България ♜

Стратегическа тривия игра за трима играчи върху интерактивна карта на България (28 области).
Териториите се завладяват с въпроси от обща култура.

## Бърз старт

Нужен е само [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
dotnet run --project src/BulgariaConquest.Server
```

Отвори <http://localhost:5283>.

* **Сам срещу ботове** – въведи име, избери трудност и натисни „Играй срещу ботове“. Двама ботове заемат
  останалите места и играта започва веднага.
* **С приятели** – „Създай игра“ и сподели 5-символния код. За тест на един компютър отвори три раздела
  на браузъра (всеки раздел е отделен играч).

```bash
dotnet test
```

## Технологии и защо

| Част | Избор | Причина |
|---|---|---|
| Сървър | ASP.NET Core (.NET 10, C#) | Познат език; лесен за хостване навсякъде (Azure, Render, Fly.io, Docker). |
| Реално време | SignalR (WebSockets) | Трима играчи трябва да виждат ходовете и въпросите мигновено; вграден в ASP.NET Core. |
| Клиент | Чист JavaScript (ES модули) + SVG | Без build стъпка и без Node; SVG дава остра, кликаема карта при всякакъв размер. |
| Данни | JSON файлове | По изискване – без база данни. Скрити зад интерфейс, за да се смени лесно по-късно. |

## Как работи играта

1. **Чакалня** – създателят споделя 5-символен код; нужни са 3 играчи.
2. **Избор на замък** – всеки избира област за своя замък (3 кули). Замъците не може да са съседни.
3. **Разпределение** – числов въпрос; най-близкият отговор (при равенство – по-бързият) заема 2 свободни
   области, вторият – 1. Повтаря се, докато картата се запълни. Заеманите области трябва да граничат с твоите.
4. **Битки** – по ред всеки играч напада съседна вражеска област. Въпрос с 4 отговора (15 сек.):
   нападателят печели само ако той е прав, а защитникът – не. Ако и двамата са прави – числов въпрос.
5. **Замък** – всяка успешна атака събаря една кула; при 0 кули притежателят отпада, а нападателят взима
   всичките му земи и точки.
6. **Край** – след зададения брой рундове (по подразбиране 6) печели играчът с най-много точки
   (200 за област, 1000 за замък; руините на паднал замък – „стара столица“ – също носят 1000 на
   този, който ги държи). Стойността на всяка област е изписана на картата.

Ако играч не действа навреме, сървърът избира вместо него (случаен замък/област) или пропуска хода му.
Всички числа са в `Data/game-settings.json`.

## Жокери и чат

Всеки играч има четири жокера, всеки за еднократна употреба през цялата игра. Първите три се ползват,
докато тече въпрос, а „Тема“ – в битките, на твой ход, преди да нападнеш:

| Жокер | Кога | Какво прави |
|---|---|---|
| **50:50** | въпроси с А/Б/В/Г | маха два грешни отговора |
| **📜 Летописец** | числови въпроси | дава интервал с верния отговор вътре (20 години при година, ±8% иначе) |
| **📞 Приятел** | всички въпроси | предлага отговор – прав е в ~80% от случаите, казва и колко е сигурен |
| **🎯 Тема** | битки, преди атака | избираш категорията на въпроса за следващата си атака (и на числовия въпрос при равенство); изборът се вижда от всички |

Резултатът от първите три вижда само играчът, който е ползвал жокера; другите виждат само, че е ползван.
Правилата са в `Core/Game/GameEngine.Extras.cs`.

Чатът е в страничната лента; в него се появяват и събитията от играта.

## Ботове

Ботовете играят по същите правила през `GameEngine` – сървърът ги задвижва на всеки тик (4 пъти в секунда).

| Трудност | Верни отговори (4 варианта) | Грешка при числов въпрос | Време за мислене |
|---|---|---|---|
| Лесен | ~45% | ~6% от отговора | 5–14 сек. |
| Нормален | ~65% | ~2,5% | 3,5–11 сек. |
| Труден | ~85% | ~1% | 2–8 сек. |

Бързият човек може да изпревари бота при равни отговори. Нормалните и трудните ботове пазят земите си
компактни, нападат лидера и довършват замъци с една останала кула. Лесните нападат случайно.
На лесни въпроси ботовете грешат по-рядко, на трудни – по-често.
Числата се настройват в `Core/Bots/BotBrain.cs` и `BotDirector.cs`.

## Данни (JSON)

* **Въпроси** – 500 с четири отговора (`choice.json`) и 500 числови (`numeric.json`) в 8 категории:
  История, География, Спорт, Литература, Математика, Наука, Изкуство и музика, Природа. Всеки въпрос има
  `category` и `difficulty` (`easy` / `medium` / `hard`). Вариантите на въпросите с избор се разбъркват
  автоматично, така че `correctIndex` може винаги да е същият. Жокерът „Тема“ предлага категориите
  от `/api/categories`.
* **Игри** – всяка игра е `App_Data/games/<КОД>.json` и се записва след всяко действие (атомарно).
  След рестарт на сървъра игрите продължават от същото място.
* **Карта** – `wwwroot/data/map-geometry.json` (SVG контури) е готова в репото. Генерира се от снимка
  `docs/reference/bulgaria-provinces.png` (карта на 28-те области, оцветени по области), която не е
  включена в репото – сложи своя, ако искаш да прегенерираш контурите:

  ```bash
  dotnet run --project tools/MapBuilder              # само геометрията
  dotnet run --project tools/MapBuilder -- --provinces  # + презаписва Data/provinces.json
  ```

  Инструментът разпознава областите по цвят, слива парчетата, разделени от надписи, и строи
  общи граници (без пролуки между съседите). Съседствата се изчисляват автоматично.

## Разширяване

* Нова механика → метод в `GameEngine` + тест в `GameEngineTests` + метод в `GameHub` + бутон/клик в `js/main.js`.
* База данни по-късно → нова имплементация на `IGameRepository` (напр. SQLite/PostgreSQL/Cosmos) и смяна
  на един ред в `Program.cs`. Правилата не се променят.
* Повече играчи → `maxPlayers` и `playerColors` в `game-settings.json`.

## Качване в GitHub и хостване

```bash
git add .
git commit -m "Initial version"
git remote add origin https://github.com/KristyanVasilev/battleForBulgaria.git
git push -u origin main
```

GitHub Pages **не стига** (хоства само статични файлове, а играта има сървър). Подходящи варианти:

* **Docker** (Render, Fly.io, Railway, Azure Container Apps) – в репото има `Dockerfile`:
  ```bash
  docker build -t bulgaria-conquest .
  docker run -p 8080:8080 bulgaria-conquest
  ```
* **Azure App Service** – директно `dotnet publish`; включи WebSockets в настройките.

Записаните игри са във файловата система – при хостинг с временен диск задай
`Storage__GamesDirectory` към постоянен том (или премини към база данни).
